One satirical sentence, at most 320 characters, roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. Judged in six private rounds by a judge model comparing two entries at a time on bite, aim and freshness. The top ten lines split the $2 reward.

## Run it

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (deterministic: the same bytes on every run).
